Q&A

What does Poofcakes mean?

I literally used a random name generator when I was like 14, and that's what I've stuck with since then. 😅

Is this your full-time job?

Nope. I'm a bioinformatics researcher by day. The game tools are a hobby I build in my spare time because I wanted them to exist. 😊

Can I request a tool or report a bug?

Yes please. 🙏 Discord is the best place for that. I read everything. 🙂

Do your tools upload my files or data?

Where I can help it, no. Most tools run in your browser and keep things on your machine. If a project works differently, its page says so. 😌

Are these tools free?

Yes. No paywalls, no ads, no account required for the browser tools. 😊 Tips are always welcome on Ko-fi if you want to support the work. I put a lot of time into some of these tools. 🥰
